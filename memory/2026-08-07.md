### 核心概念澄清

**销售组织 vs 产品组 vs 销售范围**：
- 销售组织 = 卖东西的主体（如"国内销售部""海外销售部"）
- 产品组 = 产品分类维度（如"手表""配件"），用于报表和定价
- 销售范围 = 销售组织 + 分销渠道 + 产品组 → **主数据维护的最小单位**
  - 客户/物料主数据的销售视图、定价条件、销售报表都按销售范围切
  - 设计原理：每建一个销售范围 = 多维护一整套主数据，所以只建真实需要的

**利润中心 vs COPA**：
- 利润中心 = 单值字段，一个物料卖到某地区/渠道，归属到一个利润中心（组织层面归属）
- COPA（获利能力分析）= 多维度分析框架，用特征（产品/地区/渠道）组合切利润（分析层面多维切分）
- **⚠️ 关键认知对齐**：MES 的 channelId → 对应 SAP 侧是 COPA 特征（分析标签），不是利润中心也不是分销渠道

**销售视图**：
- 客户/物料主数据中按销售范围区分的视图
- 不同销售范围可有不同价格、交货条件、币种
- 设计原理：同一客户在不同渠道（线上/线下）可能有不同合作条件

### 业务术语
- **大 KA**：Key Account，大客户/关键客户（如大型连锁零售商）
- **FOB 深圳**：Free On Board 深圳，贸易术语——卖方负责到深圳港装船，之后风险/运费归买方
- **月台**：仓库装卸货区域（loading dock），物流节点
