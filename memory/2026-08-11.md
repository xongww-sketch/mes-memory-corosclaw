4. 「真实年月」定名为 **「累计不良率（按故障发生月）」**，配套「使用月龄」补全为「累计不良率（按使用月龄）」

#### defective_date 验证结果（56,933 条全表）
| 指标 | 数值 |
|---|---|
| `defective_date` 空值 | 6 条（0.01%） |
| 未来日期 | 1 条 |
| 不良早于激活（倒挂） | **239 条**（0.42%） |
| `duration_days` 负值（Unix溢出） | **3,843 条** |

**关键发现**：现网 Tab5/Tab6 含 `AND dr.defective_duration_days >= 0`，把 3,843 台真实故障设备全部挡在统计外 → **现网不良率偏低约 6.75%**。

#### 现状口径盘点：四套并存
| 页面 | 失效时点依据 | 脏数据过滤 |
|---|---|---|
| Tab1/2 | 不判定 | 无 |
| Tab3 | `defective_date` | 无 |
| Tab4 | `duration_days` | 无 |
| Tab5/Tab6 | 激活+duration反算 | **`>= 0`** |

#### 统一口径定义（已定）
```sql
COUNT(DISTINCT ar.retroid)
WHERE dr.defective_date IS NOT NULL           -- 排除6条
  AND dr.defective_date <= NOW()              -- 排除1条
  AND dr.defective_date >= to_timestamp(COALESCE(sfa.first_activatetime, ar.activatetime)::bigint)  -- 排除239条
```
共排除 246 条（0.43%），比现网排除的 3,843 条少一个数量级。

**算法一行不动**（威布尔拟合、失真分界、失效数<5不出曲线等），只换取数来源。
