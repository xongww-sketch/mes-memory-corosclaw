**场景**：树莓派 + Node-RED 扫码 → 调 n8n 工作流 → 录入样机

### 业务需求
产线样机抽走时，扫码录入对应工单的样机信息。三个入参全部通过扫码获取：
- **SN**（扫码枪，HID 模式）
- **录入原因**（二维码，内容为中文）
- **操作人工号**（二维码）

### 数据流设计
```
扫码 → Node-RED(树莓派) → n8n webhook → 
  ① 根据 SN 查工单信息（retroid → joborder → ticketNo）
  ② 保存记录（ticketNo + retroid + 录入原因 + 操作人 + 操作时间）→ 新记录表
  ③ 调 Server 通用接口更新样机数：POST /joborder-stats/station-update { ticketNo, sampleQty }
```

### 关键决策（多轮确认）

| # | 决策 | 理由 |

| 1 | 数量更新交给 Server 通用接口 `/joborder-stats/station-update` | n8n 已有调用此接口的工作流，复用 |
| 2 | 样机 SN 抽走后不走产线了 | 物理隔离 |
| 3 | 样机 SN 状态不用动 | 不需要改 SN 主状态机 |
