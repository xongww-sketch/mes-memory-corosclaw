### ⭐⭐ Tab1 真凶：COALESCE跨表导致索引失效
```sql
WHERE COALESCE(sfa.first_activatetime, ar.activatetime) >= 常量
```
过滤条件同时依赖主表列和从表列 → PG必须先完成全表JOIN才能求值 → 索引完全失效 → 271万行全表扫。

**教训：判断SQL能否走索引，不能只看「列是否被函数包裹」，还要看「条件是否跨表」。**

**改法**：等价拆分为UNION ALL两个互斥分支，两分支条件都只涉及单表列，索引可用。

### Tab3：flatMap展开导致222次数据库往返
改法：月份区间转SQL VALUES表，一次JOIN出矩阵→2次。

### 索引杀手写法
`to_timestamp(COALESCE(...)::bigint) >= '2024-01-01'::timestamp` → 列被函数包裹走不了索引
改为 `COALESCE(...) >= EXTRACT(EPOCH FROM '2024-01-01'::timestamp)::bigint`（裸列比常量）

### ⚠️⚠️ 数值对拍抓到的两次致命错误

## 四、Lowcoder 参数教训（⭐⭐ 最重要）

**本轮4个bug，3个同一病根：参数名靠猜写驼峰，实际源码是短横/小写。**

| 我猜的（错） | 源码真实值 | 后果 |
|---|---|---|
| `compType: "js"` | **`"runScript"`** | 按钮点击完全无反应 |
| `selectType: "checkbox"` | **`"check"`** | 勾选模式没生效 |
| `checkedStrategy: "showParent"` | **`"parent"`** | 策略无效 |
| `treeCheckable: true` | **该字段不存在** | 无效字段 |
| （漏设）`checkStrictly` | **必须 `false`** | 勾父级子级不联动 |

**已核实的枚举值**：
- 事件动作compType（11个）：`empty/executeQuery/executeComp/runScript/setTempState/triggerModuleEvent/openAppPage/message/goToURL/copyToClipboard/download`
- treeSelect：`selectTypeOptions=single|multi|check`；`checkedStrategyOptions=all|parent|child`
- cascader **不支持多选**，多选级联必须用treeSelect

**规矩：以后凡Lowcoder组件参数，一律先grep前端包确认枚举值再写，不许猜。**

### 另外两个坑
1. `tempState.value`是字符串，`"2"+1="21"`，所有运算必须`Number()`强转
2. `dateRange`空值返回`"1970-01-01"`而非空串，前后端都要`nd()`归一化
